# Contributing to mcp-cost-guard

We love welcoming external contributors! Every merged Pull Request helps make LLM tooling safer and more predictable for developers.

## Quick Setup for Contributors
1. Fork the repository on GitHub.
2. Clone your fork locally:
   ```bash
   git clone https://github.com/<your-username>/mcp-cost-guard.git
   cd mcp-cost-guard
   pip install -e .
   pip install pytest
   ```
3. Run the test suite to verify everything passes:
   ```bash
   pytest -v
   ```
4. Pick any open issue labeled `good first issue` or `help wanted`, create a branch, add a test for your change, and open a Pull Request!
